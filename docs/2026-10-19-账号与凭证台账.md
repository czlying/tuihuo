## 四、密钥轮换 / 泄露处理

1. **轮换流程**：访问管理 → API 密钥管理 → 新建密钥 → 复制新 SecretId/SecretKey → 更新云函数环境变量 → **重传部署** → 确认可用 → 禁用/删除旧密钥。
2. **疑似泄露**（如完整密钥出现在截图/公开场合）：立即禁用旧密钥 → 新建 → 更新环境变量 → 重传部署。
3. **注意**：SecretKey 只在创建时显示一次，找不回完整值就只能新建。
