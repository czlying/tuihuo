## 三、平台规则与限制（重要，别踩）

### 3.1 微信小程序主体限制
| 能力 | 个人主体（身份证） | 企业 / 个体工商户 |
|---|---|---|
| 订阅消息（推送提醒） | ❌ 不可用 | ✅ 可用 |
| 微信支付（收会员费） | ❌ 不可用 | ✅ 可用 |
| 可选服务类目 | 极少 | 几乎全开放 |

- **本项目当前 = 个人主体** → 推送提醒、会员收费均不可用，只能靠**应用内**提醒（首页临期/逾期名单 + 角标）。
- **解锁路径**：升级为**个体工商户**（办营业执照，多地免费、当天可取），个体户算企业主体。
- 主体**以后能改**，但个人→个体户要走「迁移」：**审核费 300 元 + 公证几百元**。若小程序尚未积累数据，**用新执照重新注册一个更省钱**（免迁移费与公证）。

### 3.2 认证 vs 备案（两个概念别混）
| 项 | 费用 | 是否必需 |
|---|---|---|
| 微信认证 | 300 元/年 | **个人主体免认证**也能发布 |
| ICP/小程序备案 | 免费 | **正式对外发布必须**；开发版/体验版**豁免** |

- 自用/体验版阶段：**不认证、不备案都能用**。
- 正式上线（别人搜得到）：必须备案（免费，审核 1–20 工作日）。

### 3.3 腾讯云 OCR 计费
- **通用文字识别 1,000 次/月免费**：每月 1 号自动发放，**当月有效、不累积**；多项 OCR 服务**共享**这 1,000 次。
- 超额才后付费（阶梯价），**失败调用也可能计费**。
- **务必关闭「后付费」开关**（本机已关）：超额后服务停用但绝不扣钱。
- 本项目录一单消耗 1 次，个人自用远用不到上限。

### 3.4 腾讯云 CAM 权限
- **主账号密钥默认全权限；子账号密钥默认无权限**，必须显式授权。
- 调 OCR 需给子账号授权策略 **`QcloudOCRFullAccess`**，授权**立即生效**，无需重传部署。
- 本项目使用**子账号 `anne`** 的密钥 → 因此必须完成该授权。

## 四、部署 / 运维固定动作（清单）

1. **上传云函数**：微信开发者工具 → 右键 `cloudfunctions/api` →「上传并部署：**云端安装依赖**」（有 npm 依赖时必选此项）。
2. **改环境变量**：云开发控制台 → 云函数 → 对应函数 → 函数配置 → 环境变量 → 编辑 → 确定 → **重传部署**。
3. **定时触发器**：`timerRemind` 的触发器**不随代码部署**，需在控制台单独配置；漏配 = 提醒静默失效。
4. **建集合**：`orders` / `settings` / `userPlatforms` 必须先在控制台手动建好并设「仅创建者可读写」，代码首次写入前集合必须存在。
5. **测试**：`node scripts/verify-models.js`（纯逻辑）+ `node scripts/verify-project.js`（结构校验）。新增测试后须做**可证伪校验**（故意破坏代码确认变红再还原）。

## 六、代码层踩坑备忘（写代码前必看）

1. **云函数运行时是 UTC**：取「今天」必须 +8h 偏移，否则 08:00 触发会算成前一天。
2. **小程序端单次查询上限 20 条**：直接 `get()` 会静默丢数据，必须用适配器 `listAll()` 翻页。
3. **WXSS 不支持** `:first-child` / `:last-child` / `:focus`，低版本 `flex gap` 不生效 → 用显式类名 + margin。
4. **`overdue` 不落库**：读取时按 `deadline < today` 派生，避免定时任务与用户操作竞争写 status。
5. **按天粒度日期用 `'YYYY-MM-DD'` 字符串**，避免 Date 转 UTC 错开一天；带时刻字段仍用 Date。
6. **编辑保存用「变更集」语义**：字段不存在=不修改，禁止用 `''`/`null` 表达“没填”。逻辑集中在 `models/order.js` 的 `buildUpdatePatch()`，测试与服务共用同一函数，**禁止在测试里复刻**。
7. **`lastRemindStage` 存的是「已推到的档位阈值」**，不是剩余天数；提醒判定用档位区间模型，避免档位当天被跳过就永久漏推。
8. **云函数纯逻辑必须拆独立文件**（如 `timerRemind/remind.js`、`api/ocr.js`）：`index.js` 顶部 require 了 `wx-server-sdk`，测试环境加载不了，逻辑留在里面就永远无法验证。
9. **AI 生成图不能用于 OCR 测试**：AI 图文字是糊的，OCR 读不出；测试样例必须用代码渲染真文字。
10. **密钥/凭证绝不写进代码**，一律走环境变量。
