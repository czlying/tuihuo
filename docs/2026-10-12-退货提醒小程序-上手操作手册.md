## 2. 第一步：导入项目

1. 打开**微信开发者工具**（已装在你电脑上）
2. 点 **「+」** 号 → **「导入项目」**
3. **目录**：选到 `D:\workbuddy\tuihuo`（注意选这一层，不要再往里点）
4. **AppID**：点输入框右侧的 **「下拉箭头」**，从列表里选你自己的小程序

## 3. 第二步：开通云开发 + 建集合

### 3.1 开通云开发（**需要你点一次**）

**先回答最常见的一个疑问：数据库要不要单独开通、单独付费？**

> **不用。** 「云数据库」不是一个独立产品，它是「云开发环境」自带的一项能力。
> 你只要**开通一次云开发环境**，数据库就自动有了，开完就能建集合，不需要再单独去开通或买什么。
> 免费的基础版每个月给的额度，对一个人记账完全够用。

**「开通云开发」和「建集合」是两件不同的事，别混：**

| | 谁来点 | 做什么 | 为什么不能自动 |
|---|---|---|---|
| 开通云开发环境 | **你本人** | 授权微信账号下的这个 AppID 使用云开发，选免费版 | 需要你的微信登录态和实名授权，程序拿不到 |
| 建 3 个集合 | **你本人** | 在控制台点「+」新建 `orders` 等 | 集合属于你的云环境，必须在控制台创建 |
| 写数据进去 | 程序自动 | 你录入一笔订单，代码自动写库 | 已实现 |

**具体怎么点：**

1. 点开发者工具**顶部工具栏的「云开发」按钮**
2. 如果弹出登录页 —— **一定要选「微信公众平台登录」**，不要选腾讯云账号
3. 如果提示还没开通 → 点开通，选**免费的基础版**（够用）
4. 开通后会进入「云开发控制台」，**这时候数据库就已经可用了**

> 怎么看开没开通？顶部「云开发」按钮能进去、不报错，就是开通了。
> 开通过程中如果让你选「按量付费」，直接忽略，选免费基础版即可。

### 3.2 建 3 个集合（**需要你点 3 次**）

在云开发控制台左侧点 **「数据库」**，然后点 **「+」** 新建集合，依次建这三个：

| 集合名 | 权限设置（建完在「权限」里改） |
|---|---|
| `orders` | **仅创建者可读写** |
| `settings` | **仅创建者可读写** |
| `userPlatforms` | **仅创建者可读写** |

> **权限怎么改**：点集合名 → 右上角「权限设置」→ 选「仅创建者可读写」→ 保存。
> 这一步**很关键**，选错会导致你的数据被别人看到，或者你自己读不出来。

如果你想知道这些集合里面有什么，看需求文档 §8；现在不用管，程序会自己写数据。

## 4. 第三步：部署云函数

回到开发者工具，看左侧文件树的 **`cloudfunctions`** 文件夹（图标是朵云）。

**依次对下面两个文件夹操作**（操作完全一样）：

1. 右键 `api` → 点 **「上传并部署：云端安装依赖」**
2. 等右下角提示「上传成功」（约 10~60 秒，第一次会久一点）
3. 同样操作 `timerRemind`

### 4.1 额外一步：开启每日定时

只有 `timerRemind` 需要：

4. 右键 `timerRemind` → 点 **「上传触发器」**

> ⚠️ **这一步绝对不能漏**。定时触发器不跟着代码走，必须在控制台/工具里单独上传。
> 漏了的话小程序能正常用，但**永远不会给你发提醒** —— 而且是静默失效，没有任何报错。

上传完可以在云开发控制台 → 云函数 → `timerRemind` → 「触发器」里看到一条 `dailyRemind`。

### 4.2 想显示真实星座运势：配一个 Key（**需要你点 3 次**）

不配也能用——首页运势卡会自动显示本地文案，不报错。想换成聚合数据的真实运势，做下面三步：

1. 到聚合数据后台（`juhe.cn`）注册，找到「星座运势」接口，点**申请/开通**（不申请的话调用会报「无权限」）
2. 云开发控制台 → 云函数 → `api` → **配置** → **环境变量** → 添加一行：
   - 变量名：`JUHE_KEY`
   - 变量值：你在聚合数据后台复制的 Key（**不要带空格或换行**）
3. 保存后回到开发者工具，**右键 `cloudfunctions/api` → 再次「上传并部署」**（环境变量要随新版本才注入）

配完回小程序，进 **设置页 → 运势接口自检 → 检测运势接口**，会直接告诉你结果：

| 自检显示 | 含义 | 怎么办 |
|---|---|---|
| 云端 api 不是最新代码 | 新代码没上传 | 右键 `api` → 上传并部署 |
| 云函数没读到 JUHE_KEY | 变量没配到 `api`，或配完没重新部署 | 按上面第 2、3 步重做 |
| JUHE_KEY 首尾带空格或换行 | 复制时带进了空白 | 删掉变量，只粘贴 Key 本身 |
| Key 无效（10001） | Key 不对应这个接口 | 回后台重新复制 |
| 接口未开通或无权限（10002） | 没申请「星座运势」接口 | 后台申请后再自检 |
| 接口通了，但没解析到文案 | Key 和权限都正常，是返回格式与解析对不上 | `2026-10-24.17` 已兼容「数组包裹」「data/list 容器」「没有 result 就用顶层字段」「只给分值」四种返回；重新部署 `api` 后再检测，仍不行就看卡片最下面的原文 |
| 接口正常，文案已取到 | 云端没问题 | 首页仍显示本地文案就是前端包旧了 |

## 5. 第四步：试一下

1. 回到模拟器，点右下角 **「+ 记一笔」**
2. 填：商品名、平台、金额、收货日期（默认今天）

回到首页，应该能看到：
- 顶部「待退总额」变成你刚填的金额
- 下面「临期名单」出现这一条，带倒计时

**再试几个有意思的：**
- 把**收货日期改成 8 天前** → 保存后首页那条会变成红色「已逾期 N 天」
- 把**退货天数改成 15**（有些平台是 15 天）→ 最晚可退日会自动往后推

## 6. 出问题了怎么查

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 首页提示「云数据库集合不存在」 | 集合没建 | 回到第 3.2 步建 `orders`、`settings`、`userPlatforms` |
| 首页提示「没有权限」 | 集合权限设错了 | 集合 → 权限设置 → 改成「仅创建者可读写」 |
| 提示「云开发未初始化」 | 云开发没开通，或环境 ID 填错了 | 确认「云开发」按钮能进去；多环境时才需要在 `config/env.js` 填 ID |
| 保存时报「未知动作」 | `api` 云函数没传上去 | 右键 `cloudfunctions/api` → 上传并部署 |
| 云函数右键没有「上传并部署」 | 云开发没开通 / 没选中正确的云环境 | 先在「云开发」里选好环境，再回来右键 |
| 模拟器白屏 | 基础库版本太低 | 详情 → 本地设置 → 调试基础库 → 选 3.5.5 以上 |
| 提醒一直不发 | 正常，见下方说明 | 见 §7 |
| 运势配了 Key 还是显示本地文案 | 云端代码旧 / 变量没注入 / Key 无效 | 设置页 → 运势接口自检，按提示修；见 §4.2 |

**看日志的地方**：云开发控制台 → 云函数 → 点函数名 → 「日志」标签页。
定时任务跑了什么、发了几条，都在里面。

## 7. 关于「提醒」，你需要知道的两件事

### 7.1 提醒现在还发不出去，需要配一个模板

微信规定：小程序给用户发提醒，必须用**平台上审核过的消息模板**。

现在的状态是：**扫描和判断逻辑都写好了、跑得通，但没有模板 ID，所以不会真的推送**（函数会在日志里打印「本该提醒哪几笔」，方便你验证逻辑对不对）。

要真正收到微信提醒，需要：

1. 打开 [微信公众平台](https://mp.weixin.qq.com) → 登录你的小程序
2. 左侧「功能」→「订阅消息」→ 「公共模板库」
3. 搜「退货」「到期」之类的关键词，选一个合适的模板并添加
4. 复制**模板 ID**
5. 到云开发控制台 → 云函数 → `timerRemind` → 「配置」→ 环境变量，加一条：
   - 变量名：`REMIND_TEMPLATE_ID`
   - 变量值：你刚复制的模板 ID
6. 保存后，重新上传一次 `timerRemind`

> 模板里的字段名（比如 `thing1`、`time3`）要和代码里对的上一一对应。
> 对不上会报 `47003`。到时候把你选的模板发我，我帮你改代码。

### 7.2 微信的提醒有额度限制

微信的「一次性订阅」是**用户授权一次，只能发一条**。所以：

- 用户每点一次「允许」，你就多一条发送额度
- 想做到「提前 3 天、1 天、当天」各推一次，需要攒 3 次授权

这是微信的硬规定，不是代码问题。后续可以做一个「攒授权」的引导按钮，属于下一轮的事。

## 9. 每次改完代码要做什么

改完代码后，在项目根目录跑这两条命令：

```bash
node scripts/verify-models.js    # 业务逻辑自测（81 项）
node scripts/verify-project.js   # 项目结构自测（30 项 + 校验器自检）
```

**什么时候必须跑：**

| 改了什么 | 跑哪个 |
|---|---|
| 算日期、算倒计时、金额换算、表单校验、提醒档位、编辑保存 | `verify-models.js` |
| 界面（wxml）、按钮事件、加页面、加文件 | `verify-project.js` |
| 不确定 | 两个都跑 |

`verify-project.js` 专门抓一类**编译不报错、点下去才发现没反应**的问题：比如 wxml 里写了个按钮事件名叫 `onAdd`，但 js 里其实叫 `onSave` —— 编译完全正常，你点按钮就是没反应，靠自己找很痛苦。

两个脚本都会打印 `OK` / `FAIL`，有问题时退出码非 0。

> 改完界面想看效果，直接在开发者工具里按 `Ctrl+B` 编译。

### 关于本机的开发者工具命令

我探测时发现开发者工具的**服务端口是关闭的**（设置 → 安全设置 → 服务端口）。这个只影响「用命令行自动部署」，**不影响你手动点右键上传**，所以不用管它。

如果你希望以后能让我用命令行帮你自动部署云函数，到这个位置把它打开就行：开发者工具 → 设置 → 安全设置 → 服务端口 → 打开。
